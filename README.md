One haiku about debugging, written for the [Seventeen Syllables of Debugging](https://make.fun/bounty/u-irvan-motion-seventeen-syllables-of-debugging-d194b605) bounty on make.fun.

```
the duck says nothing
I explain the bug out loud
and hear the answer
```

`main.py` (stdlib only, no network) writes the haiku to `/output/entry.txt` — three lines in the 5-7-5 syllable shape, 69 bytes, well under the 200-character gate — and reads the file back to verify it holds exactly the haiku.
